# Notificación de problemas de seguridad

No publicar datos de pacientes, contraseñas, cadenas de conexión ni pruebas con información real en issues públicos. Para comunicar un problema usar el mecanismo privado de reporte de vulnerabilidades de GitHub si el propietario lo habilita; en caso contrario contactar al propietario por un canal privado acordado.

Incluir versión o commit, condiciones necesarias, pasos reproducibles con datos sintéticos e impacto. El proyecto no declara una certificación de seguridad ni tiempos de respuesta garantizados.

Las correcciones y los límites de confianza están documentados en AUDITORIA-SEGURIDAD.md y MODO-SERVIDOR-SEGURO.md. Ejecutar Validar-Seguridad.ps1 antes de distribuir una versión y mantener .NET y SQL Server actualizados.
